## 2024-05-15 - Unlabelled Icon Only Buttons for Interaction
**Learning:** Found an accessibility issue pattern specific to this app's components, where decorative interaction icons (`<Pencil>` for editing teams) were used without `aria-label` or keyboard focusability, causing screen readers to miss them completely. Also, utilizing hover states (`opacity-0 group-hover:opacity-100`) without `focus-within` hides interactive elements from keyboard-only users.
**Action:** Always ensure that icon-only interactive elements receive `aria-label`, `tabindex="0"`, `focus-visible` states, and handle appropriate keyboard events (`@keydown.enter`, `@keydown.space.prevent`). When elements are visually hidden until hovered, always pair hover classes with `focus-within` on the parent to guarantee visibility during keyboard navigation.
