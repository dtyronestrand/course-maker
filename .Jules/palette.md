## 2024-07-24 - Vue h() Render Function Accessibility
**Learning:** In Vue `h()` render functions (frequently used in libraries like TanStack table column definitions), directly appending event handlers to components like SVGs (`lucide-vue-next` icons) creates critical accessibility barriers. The table cell context does not automatically confer interactive semantics.
**Action:** When rendering interactive icons within `h()`, always wrap them in an `h('button', { 'aria-label': '...', class: 'focus-visible:ring-2 ...' }, [h(IconComponent, ...)])` element. Apply `focus-visible` ring utilities explicitly since native `<button>` focus styling may be stripped by reset CSS or lack adequate contrast without standard Tailwind forms integration. Also, if the button relies on `group-hover` visibility, ensure `focus:opacity-100` is also added so keyboard users can discover it.
