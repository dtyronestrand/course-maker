## 2026-08-29 - Input and Label ID Association\n**Learning:** In standard forms, `<label for="...">` only provides accessibility and click-to-focus benefits if there is a matching `<input id="...">`. Found multiple instances where the `id` attribute was missing on inputs while the `for` attribute existed on the label, which broke this relationship for screen readers.\n**Action:** Always verify that input fields have an `id` attribute that exactly matches the `for` attribute of their associated label.
