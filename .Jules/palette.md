## 2025-03-08 - Accessible Render Functions in Vue Tables
**Learning:** When using TanStack Vue Table and Vue's `h()` render function to define custom cell actions (like Edit/Delete icons), applying interaction attributes (like `onClick`) and `cursor-pointer` directly to icon components (e.g., `lucide-vue-next` SVGs) renders them completely inaccessible to keyboard users and screen readers, as they lack semantic roles and focus visibility.
**Action:** Always wrap interactive SVGs inside native `h('button')` elements. Crucially, explicitly add `aria-label` attributes to the button, and apply Tailwind focus ring utilities (`focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 outline-none`) to ensure the action is discoverable and usable via keyboard navigation.
