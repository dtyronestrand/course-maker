## 2024-10-02 - TanStack Table Filter Accessibility
**Learning:** Filter components built inside TanStack Vue tables often completely lack structural accessibility properties out of the box. Specifically, numeric `<DebouncedInput>` wrappers, icon-only toggle buttons, and standard `<select>` dropdowns all lack contextual `aria-label`s. Furthermore, custom table filter dropdowns typically miss basic `aria-expanded` and `focus-visible` indicators.
**Action:** When implementing custom table UI layers (like `Filter.vue`), ensure you explicitly map `aria-label`s to numeric min/max inputs, bind `aria-expanded` dynamically to toggle states, hide purely decorative sub-icons (like `lucide` items) with `aria-hidden="true"`, and enforce keyboard visibility with `outline-none focus-visible:ring-2 ...` classes.
