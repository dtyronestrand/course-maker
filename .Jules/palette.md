## 2024-05-20 - Adding Accessibility to Render Function Icons in Vue
**Learning:** When using TanStack table or custom Vue render functions (`h()`), developers often add click handlers directly to icon components (e.g., `h(Pencil, { onClick: ... })`). This breaks accessibility, as icons cannot receive focus, have no semantic meaning, and cannot be activated via keyboard. Furthermore, visually hidden elements (like `opacity-0 group-hover:opacity-100`) will remain hidden for keyboard users when they tab to them.
**Action:** Always wrap clickable icons rendered via `h()` in a native `h('button')` element containing an `aria-label`, focus ring utilities (e.g., `focus-visible:ring-2`), and ensure hidden interactive elements receive `focus:opacity-100` so they become visible when focused via keyboard.
