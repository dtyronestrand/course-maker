## 2024-05-18 - Native Buttons in TanStack Vue Table Render Functions
**Learning:** When using `h()` to define interactive elements (like SVG icons) inside a TanStack Vue table column configuration, applying `role="button"` or `tabindex="0"` directly to the SVG or its surrounding container is less accessible. You need to use `h('button')` with an `aria-label` attribute and explicitly set `focus-visible` classes (such as `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-offset-1`) so they are navigable by keyboard. When using groups to show elements on hover (`group-hover:opacity-100`), ensure keyboard users can still see the element on focus by appending `focus:opacity-100` alongside `opacity-0`.
**Action:** Use native `<button>` element structures with ARIA labels and focus states within `h()` render configurations rather than making SVGs themselves interactive via `click` and `tabindex`.
