## 2024-05-18 - Wrapping Render Function Icons for Accessibility
**Learning:** When using Vue's `h()` render function to define custom interactive elements (e.g., inside TanStack table column definitions), plain SVGs mapped to click handlers fail basic accessibility standards. They cannot be focused via keyboard navigation, and screen readers will ignore them or read out confusing node structures.
**Action:** Always wrap clickable icons generated via `h()` inside an `h('button')` element containing an explicit `aria-label` string. To ensure keyboard support, standard Tailwind focus rings (`focus-visible:ring-2 ...`) must be applied to the button, and the inner icon must have `aria-hidden='true'` to prevent duplicate announcements. Furthermore, if a button is visually hidden until hover (`opacity-0 group-hover:opacity-100`), ensure it also has `focus:opacity-100` so it becomes visible to keyboard-only users when tabbed into.
