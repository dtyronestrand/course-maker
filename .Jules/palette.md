## 2024-05-15 - Interactive Vue elements need explicit focus and aria-labels\n**Learning:** TanStack table components like custom filter toggles lack accessibility by default. An icon-only button triggering a dropdown needs `aria-label`, `:aria-expanded`, and explicit focus styling (`focus-visible:ring-2` etc.) to be discoverable via keyboard.\n**Action:** Always verify keyboard navigation and screen reader semantics for custom interactive UI components that deviate from the standard design system components.
