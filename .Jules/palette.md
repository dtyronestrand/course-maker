## 2024-08-03 - Improve Keyboard Accessibility of Icon-Only Table Actions
**Learning:** In Vue apps rendering table columns dynamically (like `@tanstack/vue-table`), inline custom elements built with `h()` (such as simple SVG icons) completely skip semantic accessibility properties if left un-wrapped. Action icons that only display on row hover (`opacity-0 group-hover:opacity-100`) are fundamentally inaccessible to keyboard users navigating via Tab if they lack `focus:opacity-100`.
**Action:** Always wrap interactive SVG icons rendered via `h()` in native `button` elements that carry explicit `aria-label` definitions and standard focus rings (e.g. `focus-visible:ring-2 ... outline-none`). Ensure that hover-only action elements explicitly receive `focus:opacity-100` so that keyboard navigation reveals the elements effectively without needing mouse presence.
