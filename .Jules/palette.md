## 2024-10-09 - Accessible Icon Buttons in Vue Render Functions
**Learning:** When using Vue's `h()` render function (common in TanStack Table configurations or dynamic components) to display icons that act as actions, simply applying an `onClick` listener to the SVG component directly (e.g., `h(Trash2, { onClick: ... })`) creates an inaccessible interaction pattern. The element lacks keyboard focusability, screen reader labeling, and appropriate semantic meaning.
**Action:** Always wrap interactive icon-only components in an `h('button')` element when using render functions. Ensure the button has an `aria-label` describing the action, and apply proper Tailwind focus ring utilities (`focus-visible:ring-2 focus-visible:ring-offset-2 outline-none`) to the wrapper button to guarantee keyboard accessibility and screen reader support.
